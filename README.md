# Juego-ahorcado
Este repositorio esta echo con todo lo que fuimos viendo a lo largo del semestre pero aplicado en un programa.


Mecánica del juego
El sistema selecciona una palabra aleatoria.
Tiene guiones debajo, que representan la cantidad de letras
TIenes que ir poniendo letras de una por una
Si le atinas se pone encima del guion
Si no le atinas te vas ahorcando
Si se te acaban las vidas, pierdes y se te rebela la palabra correcta, si le atinas a todas se marca la palabra y ganaste
